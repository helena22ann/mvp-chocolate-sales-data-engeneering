# mvp-chocolate-sales-data-engeneering

Projeto desenvolvido por **Helena Ann Pereira** como MVP da disciplina de Engenharia de Dados do curso de especialização em Ciência de Dados da PUC-Rio.

A partir do [*Chocolate Sales Dataset*](https://www.kaggle.com/datasets/atharvasoundankar/chocolate-sales), este trabalho tem o objetivo de investigar o comportamento de vendas de uma operação de chocolates que atua em múltiplos países, identificando os fatores que afetam a receita. Para isso, foi construído um pipeline de dados de ponta a ponta na nuvem, passando pela coleta, modelagem, transformação e análise dos dados, visando responder às perguntas de negócio levantadas no início do trabalho.
